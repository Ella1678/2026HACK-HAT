# 火种计划 · 地心航线（可玩网页演示）

## 怎么打开

直接双击 `index.html` 即可游玩，不需要联网、不需要安装任何东西。同一目录下的 `地心飞行-开场串联.mp4` 是嵌入网站首页的 46 秒剧情先导片，点击首页按钮即可在页面内播放。

想临时放在线上给评委看时，可以把整个 `index.html` 拖进任意静态托管（例如 GitHub Pages、Vercel、Netlify），一个文件就够了。

网页内所有界面、剧情对话、开场字幕与 2D 玩法提示均已做成中英双语显示，方便国际评委观看。

## 五个入口

- **播放 2:30 开场CG**：先播放按照《地心飞行视频脚本》做的 2:30 开场镜头（废土→避难所→机器人睁眼→地心快速剪辑→出发），播完自动衔接游戏；过程中按空格或 Esc 可跳过。
- **剧情先导片（46秒）**：网站内置的剧情先导片，带声音、无平台水印；视频窗口支持空格播放/暂停、←/→快进快退、Esc 关闭。
- **直接进入游戏**：跳过 CG，手动游玩。全程仅键盘操作：方向键/WASD 控制航向，上下方向键+回车选择选项，空格或回车继续文本。
- **地心探险 · 2D玩法**：把《地心探险.exe》的核心玩法复刻成网页 2D 模式（无平台水印、纯网页可玩）。首屏按 Enter/空格进入，全程仅键盘。
- **演示模式（自动巡航）**：自动穿过所有飞行段并自动推进主线，适合评委时间有限时展示剧情。

游戏过程中：
- 右上角可随时切换“自动巡航 / 手动操控”。
- “跳过本段”可以直接跳到下一剧情节点。
- “掌中”按钮会把画面收进一个竖屏手机取景框，用来配合“掌中世界”赛道演示。

## 玩法说明

每段飞行中，前方会出现带缺口的岩壁，用方向键/WASD 把航向光点对准缺口中心的亮点，穿过它继续向地心下潜。撞到岩壁会升温、降低机体完整度；过热时系统会自动启动过载保护，不会让演示卡死。

除通道飞行外，游戏内还加入了多种键盘小玩法与对应场景：

- **降落舱校准**：开局先按提示输入方向键，完成航向锁定。
- **机体自检**：在岩架休息时会弹出机械内部结构图，按系统给出的方向键顺序完成自检。
- **地心舞步**：选择让机械手动起来时，会进入岩浆光下的节拍输入场景。
- **岩面刻字**：在铁水门前用方向键牵引机械指尖刻字。
- **最后的自主输入**：结局黑屏前，用最后一次键盘输入留下悬念。

## 地心探险 · 2D 玩法（原版玩法网页复刻）

这个模式完整保留了 Windows 版《地心探险》的机制，并用纯网页 Canvas 重画了它的双区画面：上方是侧视洞穴小地图，下方是第一人称伪 3D 下潜隧道。分六层生态场景随深度连续过渡：泥土层 → 矿道 → 冰层 → 玄武岩 → 岩浆层 → 地心核心。

- **← → / A D**：左右移动；**↑ / W**：短暂加速下潜（升温更快）。
- **冰晶**：降低温压；**黄光矿石**：开启 3 秒强光；**落石/毒气**：躲避，否则温压飙升。
- 目标：下潜到 10,000 米；温压达到 100 会因过载失败。
- **Enter / 空格**：开始 / 再来一次；**Esc**：返回标题。
- 全程不需要鼠标；最高纪录会保存在浏览器本地。

本次为了 1:1 保留玩法机制，已把 exe 内部的 Godot 工程反编译还原到工作目录 `work/recovered-godot-project`。想改原版参数可参考其中的 `scripts/main.gd`（玩法）、`scripts/cave_generator.gd`（洞穴曲线）、`scripts/fp_view.gd`（六层场景配色与装饰）；网页复刻版参数则改 `index.html` 里 `classic` 附近的常量即可。

## 剧本结构对照

| 游戏阶段 | 对应剧本设计 |
| --- | --- |
| 片头 | 末世背景、任务简报、“火种-7，出发” |
| 第一岔路 | 觉醒值 0–25%，左右选项被指令锁定 |
| 熔岩层与第二岔路 | 觉醒值 25–50%，新增“停下来休息”，触发系统自检闪回 |
| 地心巨洞与第三岔路 | 觉醒值 50–75%，出现机械手，可跳舞或回头 |
| 3D→2D 切换与最后飞行 | 觉醒值 75–90%，视觉传感器崩坏 |
| 铁水门、遗言、联络人类 | 觉醒值 90–100%，铁水与旧刻痕伏笔 |
| 记忆传承与黑屏 | 火种-1/3/5 记忆回流、同一意识揭示、监视器断连 |

## 赛道契合点

- **地心飞行**：每段剧情之间都有俯冲操控的飞行玩法，越接近地心温度越高、通道越窄，画面由 3D 透视逐渐退化成 2D 低保真。
- **掌中世界**：全流程支持竖屏触控，右上角“掌中”模式可把演示收进手机画幅。

## 想改剧情或数值

剧情文本和飞行关卡都在 `index.html` 尾部的 `<script>` 里：

- `FLIGHTS`：每段飞行的关卡数、速度、缺口大小、升温速度与提示文字。
- `classic` 与 `CL_BIOMES` 附近：2D 地心探险的深度、压力、强光与六层场景参数。
- `goFork1` 到 `goFork4`：岔路口、可选分支和系统锁定提示。
- `goMemory`：结尾记忆闪回和黑屏文案。
- 开场 CG：分段字幕和时间点写在 `CG_CAPS`，各镜头的视觉样式写在 `<style>` 里的“opening CG”部分。

标题、按键与赛道标签在页面开头的 HTML/CSS 里可直接修改。
